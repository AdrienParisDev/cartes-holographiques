# Images de l’exemple Artikodin

Les trois PNG utilisés par l’exemple sont :

- `artikodin-montagne.png` : paysage de montagnes, calque d’arrière-plan ;
- `artikodin-oiseau-retouche.png` : nouvel oiseau recadré depuis l’éditeur (image source « RT code 1 oiseau.png »), calque central ;
- `artikodin-carte-main.png` : cadre, titres et éléments graphiques, calque de premier plan.

Le recadrage de l’oiseau est intégré dans le PNG de 733 × 1024 px : il n’y a pas de position supplémentaire à configurer dans le JSON. Les anciens fichiers non utilisés restent uniquement en local et sont exclus du dépôt. Les images du catalogue doivent rester alignées sur le même ratio de carte ; le catalogue vérifie leur présence au chargement de la page.
